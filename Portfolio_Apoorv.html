02 Speaker Intelligence
Speaker Verification & Gender Classification
End-to-end pipeline using ECAPA-TDNN on a 132-speaker Hindi multi-accent dataset (12.5 hrs). Achieved 100% F1-score on gender classification. Visualized embedding space with t-SNE/UMAP showing clear cluster separability. Deployed as live Gradio demo.
ECAPA-TDNN SpeechBrain t-SNE / UMAP Scikit-learn Gradio
↗ GitHub
03 Computer Vision
Water Bridge Detection — YOLOv8
Object detection pipeline for water bridge identification from satellite/remote sensing imagery. Trained YOLOv8 on DOTA dataset achieving 58% mAP. Used OpenCV for preprocessing and Hugging Face for model management. GLH-Water identified as higher-accuracy alternative.
YOLOv8 OpenCV Hugging Face DOTA Dataset PyTorch Streamlit
↗ GitHub
04 Astrophysics · ML
QPO Detection in X-Ray Binaries
ML pipeline for detecting Quasi-Periodic Oscillations from noisy NASA astrophysical datasets. Engineered signal feature extraction and classification models across 500+ power spectra with explicit focus on false positive reduction. Under Prof. Manoneeta Chakraborty.
Astropy Stingray NumPy Scikit-learn Python
↗ GitHub

Gemma 3n Mental Health Voice Chatbot
Voice-first mental health chatbot with real-time LLM-based emotional classification and dynamic context-aware responses using Gemma 3n. Reduced response latency by ~25% via stacked memory architecture eliminating redundant context reloading. Google DeepMind Hackathon.
